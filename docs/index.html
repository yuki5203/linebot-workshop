課堂 LINE 客服示範

用 LINE 詢問服務內容與常見問題。此頁是課堂展示入口，訊息由 Make 自動化流程與 AI 模型處理。

加入 LINE（待設定公開連結）

練習前請依學員手冊設定自己的測試帳號連結。

使用方式

  1. 加入測試用 LINE 官方帳號。
  2. 傳送一段文字，例如「請介紹你的服務」。
  3. 等待回覆。AI 回答可能不正確，請以服務提供者的正式資訊為準。

資料與服務提醒

請勿傳送姓名、電話、身分資料、帳號密碼或其他機敏資訊。本次練習只使用虛構資料。

這個靜態頁面不收集表單或聊天內容。加入 LINE 後的訊息會由 LINE、Make 與所選 AI 模型服務處理。正式服務應另提供適用的隱私告知。

服務範圍

此為教學示範，功能與回應時間取決於 Make 流程、模型及服務額度。請勿將它用於緊急或高風險決策。

GitHub Pages 提供介紹頁面。LINE 客服流程仍在 Make 執行。
